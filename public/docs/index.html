Introdução

Consulta de horários livres, reserva com sinal via Pix e webhook de pagamento.

URL base: http://localhost:8080

API pública do sistema de agendamentos. O fluxo do cliente é:

  1. Consultar horários livres de um profissional para um serviço numa data.
  2. Reservar um desses horários: a API cria um agendamento pendente e devolve o Pix do sinal.
  3. Pagar o sinal em até 15 minutos. O Mercado Pago avisa o webhook, o agendamento passa a confirmado e o cliente recebe um e-mail com o link de cancelamento.

Sem pagamento no prazo, a reserva vence e o horário volta a ficar livre.

Datas e horas usam ISO 8601 com o deslocamento do fuso (2026-11-30T10:00:00-03:00). Valores monetários são inteiros em centavos (3000 = R$ 30,00).

Autenticação

Esta API não exige autenticação: a reserva é pública e o webhook é validado pela assinatura.

Disponibilidade

Listar horários livres

Horários em que o profissional pode atender o serviço na data, já descontando jornada, bloqueios (folgas, almoço), agendamentos e a antecedência mínima (2 h) e máxima (60 dias). A grade é de 30 em 30 minutos.

A lista é informativa: entre a consulta e a reserva, outra pessoa pode reservar o mesmo horário. Por isso a reserva confere de novo e pode responder 409.

Exemplo de requisição:
curl --request GET \
    --get "http://localhost:8080/api/profissionais/1/disponibilidade?servico_id=1&data=2026-11-30" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost:8080/api/profissionais/1/disponibilidade"
);

const params = {
    "servico_id": "1",
    "data": "2026-11-30",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};


fetch(url, {
    method: "GET",
    headers,
}).then(response => response.json());

Reservas

Reservar um horário

Cria um agendamento pendente, que segura o horário por 15 minutos, e devolve o Pix do sinal (copia e cola e QR Code em base64). Pago o sinal, o webhook confirma o agendamento e o cliente recebe um e-mail.

O cliente é identificado pelo e-mail, sem precisar de conta: na próxima reserva, nome e telefone são atualizados. O preço e o sinal ficam gravados no agendamento, e mudanças posteriores no serviço não os alteram.

Limite: 5 reservas por minuto por IP.

Exemplo de requisição:
curl --request POST \
    "http://localhost:8080/api/agendamentos" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"profissional_id\": 1,
    \"servico_id\": 1,
    \"inicio\": \"2026-11-30T10:00:00-03:00\",
    \"cliente\": {
        \"nome\": \"Maria Silva\",
        \"email\": \"maria@example.com\",
        \"telefone\": \"(11) 91234-5678\"
    }
}"

const url = new URL(
    "http://localhost:8080/api/agendamentos"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "profissional_id": 1,
    "servico_id": 1,
    "inicio": "2026-11-30T10:00:00-03:00",
    "cliente": {
        "nome": "Maria Silva",
        "email": "maria@example.com",
        "telefone": "(11) 91234-5678"
    }
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Webhooks

Aviso de pagamento do Mercado Pago

Chamado pelo Mercado Pago, não pelo cliente. Só enfileira e responde 200: o Mercado Pago espera resposta em poucos segundos e reenvia se não receber. O trabalho pesado (consultar a API, atualizar a agenda) fica no job.

O corpo é tratado só como sinal: o job consulta o pagamento na API do Mercado Pago, que é a fonte da verdade. Avisos repetidos ou fora de ordem não mudam nada (processamento idempotente).

A assinatura é HMAC-SHA256 de id:{data.id};request-id:{x-request-id};ts:{ts}; com o segredo do webhook; avisos com ts a mais de 5 minutos do horário do servidor são recusados.

Exemplo de requisição:
curl --request POST \
    "http://localhost:8080/api/webhooks/mercadopago?type=payment" \
    --header "x-signature: required Assinatura no formato ts={timestamp},v1={hmac}. Example: ts=1764252000,v1=5f1c...e9" \
    --header "x-request-id: Id do aviso enviado pelo Mercado Pago. Example: bb56a2f1-6aae-46ac-982e-9dcd3581d08e" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"type\": \"payment\",
    \"data\": {
        \"id\": \"1325461234\"
    }
}"

const url = new URL(
    "http://localhost:8080/api/webhooks/mercadopago"
);

const params = {
    "type": "payment",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "x-signature": "required Assinatura no formato ts={timestamp},v1={hmac}. Example: ts=1764252000,v1=5f1c...e9",
    "x-request-id": "Id do aviso enviado pelo Mercado Pago. Example: bb56a2f1-6aae-46ac-982e-9dcd3581d08e",
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "type": "payment",
    "data": {
        "id": "1325461234"
    }
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Exemplo de resposta (200, Aviso aceito e enfileirado):


{
    "recebido": true,
    "processado": true
}

Exemplo de resposta (200, Tópico ignorado (ex.: merchant_order)):


{
    "recebido": true,
    "processado": false
}

Exemplo de resposta (401, Assinatura ausente, inválida ou antiga):


{
    "message": "Assinatura inválida."
}
